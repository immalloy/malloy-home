ChromaKit is a Friday Night Funkin' modding tool for turning source audio into chromatic samples with formant correction.

It keeps the process focused: prepare a track, choose its pitch range, process the samples, and export a set ready to use in a mod.

## What it does

- **Generate chromatics:** Create pitched samples from a source track.
- **Shape the output:** Trim silence, normalize peaks, add fades, and set a fixed note length.
- **Keep samples usable:** Embed FL Studio Slicex markers and choose the output sample rate.
- **Download it:** Get ChromaKit from its GameBanana page.
